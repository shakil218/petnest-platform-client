# 🐾 PetNest – Pet Adoption Platform

## 📌 Project Purpose

PetNest is a modern full-stack pet adoption platform where users can explore pets, view detailed information, and adopt their favorite pets easily. The platform provides a smooth and responsive user experience with authentication, dynamic pet listings, advanced filtering, and beautiful UI animations.

---

## 🌐 Live URL

🔗 https://petnest-adoption-portal.vercel.app

---

## ✨ Features

- 🐶 Browse and explore available pets for adoption
- 🔍 Search, filter, and sort pets dynamically
- 📄 Detailed pet information page
- ❤️ Adopt pets with authenticated user access
- 🌙 Light/Dark theme toggle support
- 📱 Fully responsive modern UI design
- ⚡ Smooth animations using Framer Motion
- 🧾 Skeleton loading and global loading UI
- 🔐 Authentication system integration
- 🎨 HeroUI + TailwindCSS + DaisyUI based design

---

## 🛠️ Tech Stack

### Frontend
- Next.js 15
- React
- Tailwind CSS
- HeroUI
- Framer Motion
- Lucide React
- React Icons

### Backend
- Node.js
- Express.js
- MongoDB

---

## 📦 NPM Packages Used

### Frontend Packages

```bash
npm install next react react-dom
npm install tailwindcss daisyui
npm install @heroui/react
npm install framer-motion
npm install lucide-react
npm install react-icons
npm install react-toastify
npm install axios
```

### Backend Packages

```bash
npm install express mongodb cors dotenv
npm install nodemon
```

---

## 🚀 Installation & Setup

### Clone the project

```bash
https://github.com/shakil218/petnest-platform-client.git
```

### Frontend Setup

```bash
cd petnest-platform-client
npm install
npm run dev
```

### Backend Setup

```bash
cd petnest-server
npm install
npm run dev
```
